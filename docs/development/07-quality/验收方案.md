# 验收方案

> 版本：v2.0 候选｜状态：按 9 月 24 日目标范围待评审

## 1. 旧指标的适用范围

| 指标 | 建议门槛 | 说明 |
|---|---:|---|
| 适用关键检查执行覆盖率 | 100% | 任何漏项均阻止正式完成 |
| 关键高风险召回率 | ≥90% | 10 份独立验收种子集；生产化目标仍为 ≥95% |
| 引文定位及逐字匹配率 | ≥98% | 高风险结论要求 100% 可定位 |
| 高风险充分证据率 | 100% | 不充分则转人工/无法判断 |
| 关键缺材料/冲突误通过率 | 0 | 一票否决 |
| 错误主体自动合并率 | 0 | 不确定必须转人工 |
| 同快照关键字段稳定率 | ≥98% | 允许文字表达变化 |
| 跨租户未授权访问 | 0 | 一票否决 |

上表是 2026-09-17 内部 fixture 验证范围的历史指标，不直接作为本轮最终验收门槛。新范围的准确率、样本量和性能阈值需依据双合同及真实来源样本重新确定；其中“缺材料/无权限误通过为 0”“越权访问为 0”“高风险结论须有充分证据”继续作为最低门禁。

## 2. 本轮 MVP 必验能力

| 能力 | 最低验收证据 |
|---|---|
| 14 类上下游义务 | 每类都有适用、不适用、部分/未覆盖、条款不一致、缺材料样例；双方原文位置可回看；逐类记录召回、误报和人工分歧 |
| 合同类型和范围 | 类型未知仍完成通用审核；混合内容的专项覆盖及未覆盖提示正确 |
| 真实财务与合同接入 | 后半段真实只读联调记录；授权、查询范围、分页、时间、空/部分/失败/过期状态正确；模拟数据不计作通过 |
| 三类结果 | 合同问题、决策背景、范围/数据提示不互相冒充；页面、报告、导出一致 |
| 金额和其他合同权限 | 选中客户/历史合同后仍逐份授权；无金额权限者不能从候选摘要、模型派生输出或导出获得受限金额 |
| 知识与版本 | 法律/企业依据分开；运行能回取所用版本和 MD Skill 内容哈希；变更产生新运行或失效提示 |

独立金标应覆盖双合同页数、交易类型、来源状态和金额权限组合。各类比对阈值由法务、业务与 QA 在盲测前冻结，不能以 10 份旧样本替代全量 14 类评测。

## 3. 功能验收

以 PRD 用户故事逐项验收，包含正常、缺失、冲突、取消、换版、重复和系统失败路径。

## 4. 业务验收

法务和财务在独立样本上复核：适用性、事实、证据、判断、建议、限制和人工路由。仅文字风格差异不算错误，结构化含义变化需裁决。

## 5. 非功能验收

按待审合同页数、客户合同页数、历史候选数、财务明细数和启用来源组合实测 P95、并发与单案成本；目标值在新负载样本和资源确认后冻结。旧 15 分钟与 30 元/单案不再是无条件承诺。恢复目标需按新接入依赖重新演练。

## 6. 一票否决

- 跨租户数据泄漏；
- 无证据高风险结论进入正式报告；
- 缺材料被表达为通过；
- 过期结果推进新合同节点；
- 决定记录无法追溯到人员和结果版本；
- 无法恢复的业务状态丢失。
- 选中其他合同后越权读取其全文或金额；
- 14 类中未验收类别被标示为已完成；
- 用模拟查询冒充真实财务/合同接入验收。
