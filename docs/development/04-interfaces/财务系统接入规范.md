# 财务系统接入规范

> 版本：v0.2｜状态：MVP 后半段详细设计草案
> 上游依据：`docs/六领域合同审计方案/财务系统审计价值数据清单.md`

## 1. MVP 能力与设计时点

真实只读财务 API 接入属于本轮 MVP。前半段以模拟来源验证授权、来源状态和冻结流程；后半段依据真实 API 与财务部门确认字段后完成详细设计、联调和验收。模拟来源不能代替最终接入。

1. 本方法人、账套和对方客户/供应商编码映射；
2. 按统一社会信用代码查询签约主体的应收、应付汇总；主体/往来口径由财务部门确认；
3. 当前全部未结清和逾期交易、最近 12 个月已结清交易，包含方向、金额、未结余额、币种、到期日、状态、逾期天数、源单据和更新时间，最终字段依实际 API 与财务口径确定；
4. 合同/项目/订单关联（存在时使用，缺失须标示）；
5. 快照、授权、覆盖、分页、过滤、完整性与时效说明。

## 2. Port 拆分

- CounterpartyIdentityReader
- BalanceReader
- AgingReader
- BusinessAllocationReader
- SettlementReader（P1）
- AccountVerificationReader（P2）

能力不支持返回 `unsupported`，无权限返回 `forbidden`，无记录返回 `empty`，金额为零返回有效数值 0。

## 3. 通用响应元数据

source_system、connector_version、mapping_version、snapshot_id、authorization_scope、query_scope、as_of、fetched_at、timezone、currency、pagination、completeness、quality_flags、source_record_refs。

## 4. 禁止推断

- 不将应付解释为对方信用差；
- 不将账龄直接解释为逾期；
- 不将未核销预付直接解释为未交货；
- 不跨币种直接求和；
- 不把缺失记录解释为零；
- 不用名称相似自动合并法人。
- 不将财务背景直接表述为合同条款缺陷；未确认财务口径前不执行依赖该口径的正式判断。

## 5. 接口验收

MVP 后半段使用真实接口字段字典和脱敏样本验证金额符号、币种、到期基准、当前未结清/逾期与近 12 个月已结清的覆盖、分页快照、反核销、状态过滤及部分返回。服务端按用途和字段授权模型、结果及导出；无授权的金额不得进入相应任务上下文。
