# 数据保留与删除

> 版本：v1.1 候选｜状态：真实来源留存策略待确认
> 负责人：内部安全负责人
> 批准人：内部项目发起人
> 适用阶段：内部 MVP
> 上游依据：Phase 0 试点定义包、部署方案 v1.0

## 1. 数据类别

| 类别 | 示例 | 默认策略 |
|---|---|---|
| 原始材料 | 合同、附件、上游意见 | 按案件/客户要求加密留存 |
| 外部快照 | 财务、合同、外部核查响应 | 最小化字段，按授权期限留存 |
| 派生事实 | Fact、Conflict、Coverage | 与运行记录关联留存 |
| 模型数据 | 输入引用、输出、成本 | 避免保存不必要全文和隐藏思维链 |
| 决定与审计 | 决定、审批、访问、回写 | 满足审计与争议处理要求 |

## 2. MVP 保留基线

| 数据 | 默认期限 | 到期处置 |
|---|---:|---|
| 原始材料、解析产物、外部 fixture、派生事实 | 180 天 | 案件级删除或匿名化复核 |
| 运行、结果、决定和审计记录 | 180 天 | 保留最小审计记录后删除内容 |
| 应用日志 | 30 天 | 自动轮换；安全事件可登记延长 |
| 数据库和对象存储备份 | 30 天滚动 | 到期不可恢复地轮换 |
| 模型供应商输入输出 | 0 天或经批准的最短期限 | profile 必须登记并可验证 |

2026-09-17 的 180 天在线和 30 天备份期限只针对旧内部验证范围。本轮后半段接入真实财务与合同数据前，须由数据负责人确认源系统授权、允许保存的字段、用途、在线/备份期限、删除及二次使用范围；未确认前只用合成或已脱敏授权样本。出现登记的争议、安全事件或审计保全时暂停相关对象删除；解除条件和批准人写入保全记录。

## 3. 删除原则

删除请求先确认法律依据、数据控制者、案件状态和保全要求。执行后产生不可篡改删除记录，但不在记录中复制被删除内容。

## 4. 备份

备份保留期与在线数据区分；到期后通过备份轮换完成删除。恢复旧备份后必须重新应用已登记的删除/匿名化事件。

删除事件覆盖数据库、对象存储、检索索引和派生缓存；执行状态、失败对象和重试必须可查询。MVP 不承诺在 30 天备份轮换期内物理擦除离线备份，但相关数据不得恢复为在线可访问状态。
