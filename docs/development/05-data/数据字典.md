## 字段治理要求

每个字段在正式 Schema 中补齐：中文名、英文名、类型、枚举、单位、来源、敏感级别、权限、留存、校验、示例和版本。

旧 M0 核心字段由旧 OpenAPI 和首版数据库约束定义。上表新字段是逻辑契约候选，需在对应阶段完成类型、授权、来源、留存和物理迁移；不允许以 `metadata jsonb` 代替稳定业务列。真实 API 的字段映射在 MVP 后半段结合系统样本确定。

## 禁用模糊字段

不得使用无口径的 `amount`、`status`、`score`、`risk`、`date`。应使用如 `contract_total_amount`、`execution_status`、`judgment_status`、`as_of_date` 并声明口径。
