## 2. 通用列

业务表包含 tenant_id、id、created_at、created_by、version；不可变表追加 content_hash 和 source_version。软删除不得用于掩盖法律留存要求，删除/匿名化策略单独执行。

## 3. 金额与时间

- 金额使用精确 decimal，不使用 float；
- 币种使用 ISO 4217；
- 时间存储 UTC，保留业务时区；
- valid_time、as_of、observed_at、created_at 分开；
- 日期无时间含义时使用 date 类型。

## 4. 不可变性

DocumentVersion、InputSnapshot、FactSetSnapshot、AuditPlanSnapshot、CheckResult 和 DecisionSnapshot 发布后不可原地修改。纠错创建新版本并建立 replaces/supersedes 关系。主体管理员纠正案件主体不重写原 `DocumentVersion.legal_entity_id`；旧文档保持历史范围，须重新上传新版本才能用于更正后主体的新审查。

## 5. 索引

至少按 tenant_id + case_id、run_id、task status + next_run_at、external binding 幂等键、rule_id + version、evidence subject 建索引。检索索引不作为事实或规范真源。

## 6. 关键约束

- 所有跨表业务引用同时携带 tenant_id，禁止只靠全局 UUID 绕过租户条件；
- `audit_runs` 的 input/fact/plan snapshot 引用非空且发布后不可更新；
- 同一案件、同一输入快照最多一个非终态运行；
- task 的 idempotency_key 在 tenant + task_type 范围唯一；
- CheckResult 在 tenant + run + rule_id + subject_ref 范围唯一；
- Evidence 的 document_version 必须属于本次运行已授权的固定输入集合；
- 选入的历史/客户合同虽可来自其他案件或合同系统，也必须在本运行的固定授权输入集合中登记其来源、用途和文档版本后才能被 Evidence 引用；
- outbox 的 event_id 全局唯一，业务对象变更与事件插入同事务；
- 金额列同时要求 currency 和 basis；禁止 float/double；
- 所有状态列使用数据库约束或受控枚举，不接受自由字符串。
- `document_index_jobs` 与上传记录在同一事务创建，按 tenant + document_version 唯一；job 固定 `source_sha256`，Worker 通过 lease/fencing 写回 `document_indexes`，索引行必须绑定同一原件哈希。
- `tenant_entity_administrators` 是受信运维流程维护的租户级业务授权，不读取 OIDC 任意角色声明，也不等同于 `operator`；应用运行角色只读该授权表。
- `case_legal_entity_corrections` 仅追加，保留纠错人、前后主体、理由、案件版本和幂等摘要；应用运行角色无更新/删除权限。确认后普通审核人不可直接变更，仅主体管理员可按纠错流程更正并留审计。纠错可发生在选择、授权和冻结后：现有选择/材料授权撤销、案件版本递增、旧范围运行标记为 `superseded`；冻结快照和运行记录保留且不原地改写。旧结果仍受当前成员和材料授权检查；新审查必须重新选择、授权、预览和冻结。
- `case_legal_entity_correction_effects` 与每条纠错一对一、仅追加，保存被撤销的选择 ID、授权 ID、涉及的文档版本 ID、被替代的运行 ID；历史时间线从该表读取影响计数。纠错主审计和影响记录在同一事务中写入，不能出现已改主体却没有对应失效范围的半完成状态。

首版物理约束见 [首版数据库约束](首版数据库约束.sql)。实施迁移可拆分文件，但不得弱化其中的租户、幂等和不可变约束。

该 SQL 是 2026-09-17 旧物理基线，尚不能承载本轮关系、来源、知识和三类结果。M1 固定逻辑字段与授权边界；M3 结合真实接口确定来源字段和物理迁移。已执行迁移不得原地覆盖，新增版本化迁移。

## 7. RLS 会话契约

应用事务开始后设置 `app.tenant_id` 和 `app.actor_id`；tenant 表启用并强制 RLS。连接归还池前清理会话变量。后台任务同样使用租户受限角色；迁移角色与 break-glass 角色不用于日常请求。
