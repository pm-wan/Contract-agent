# 首批规则目录

> 版本：v1.0｜状态：2026-09-17 旧采购规则候选目录；非新 MVP 完整覆盖
> 场景：采购方视角的服务/软件采购协议内部预审

本目录的 12+3+1 项用于旧版内部验证和新方案中的部分采购检查候选。新 MVP 还要求合同类型兜底、三类结果和 14 类上下游义务比对；后者须另建逐类规则、证据和金标，不能以本目录项数代表新 MVP 完成度。`legal.*` 前缀不自动证明某项判断属于法律强制要求，正式发布时需标注知识域和依据性质。

## 目录冻结要求

每项规则必须完成 RuleDefinition、槽位、依据、正例、反例、缺材料、冲突和人工路由后才能标记为“可开发”。
