# 开发阶段确认记录：付款规则

## 确认结论

本项目开发阶段直接采用当前付款口径材料，不再等待逐项人工签字后才继续产品开发。确认范围包括：

- 含税总价、未税总价分别保存；税额和税率单独记录。
- 未明确币种时默认人民币；暂不支持多币种。
- 正文和价款表优先；附件、补充协议纳入核算并展示冲突。
- 付款比例默认以合同总价为分母。
- 固定金额与比例同时出现时检查一致性；不一致时固定金额优先并提示。
- 缺金额、冲突、无法计算或证据不足时，相关判断标记“需人工核对”，但不阻断其他合同检查。
- 每个判断展示原文、位置及全部相关证据。
- residual 作为未分配余额处理；any/all 不自动猜测；重复阶段不自动合并，均提示人工核对。
- 反例案例直接作为开发回归数据，不宣称为生产金标。

## 使用边界

本记录只表示“开发阶段确认”，允许工程继续实现和联调。正式生产发布仍需后续补充真实法律正文、企业制度原文、哈希、审批记录和独立评测阈值。
