# 上线与回滚方案

> 版本：v0.1｜状态：草案

## 1. 上线前门禁

- G0～G7 文档和评审完成；
- 独立金标、端到端、安全和恢复验收通过；
- 规则、模型、连接器和报告版本冻结；
- 运维值班、告警、支持和业务联系人明确；
- 外部系统失败策略和人工兜底确认。

## 2. 发布策略

先内部影子运行，再小范围试点，再扩大租户/法人/合同类型。首期默认不自动推进合同流程。

## 3. 回滚维度

- 应用版本；
- 规则包；
- 模型 profile；
- 连接器 mapping；
- 报告模板；
- 外部回写开关。

回滚不能删除已经生成的事实、结果或人工决定。新运行使用回滚后的版本，既有运行按处置方案继续、取消或重建。

## 4. 紧急停用

支持按租户、规则、模型、连接器和回写能力停用。高风险误报/漏报时暂停相关新运行，识别受影响结果并建立复核任务。

## 5. 上线后观察

观察案件完成时间、人工任务、误通过、证据失败、接口降级、成本和用户纠正模式。试点复盘决定是否进入下一合同类型。
