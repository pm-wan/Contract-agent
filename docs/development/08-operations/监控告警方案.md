# 监控告警方案

> 版本：v0.3 候选｜状态：M0 元数据追踪/低基数基础指标及可选 OTLP 导出已实现；生产观测方案待审批与验收

## 1. 四类观测

| 类别 | 指标 |
|---|---|
| 业务 | 案件量、完成率、等待项、关键检查覆盖、受限报告 |
| 执行 | 队列深度、租约超时、重试、失败、无进展循环 |
| 模型 | 延迟、错误、token、成本、Schema 失败、降级 |
| 集成 | 接口延迟、部分返回、Schema 漂移、回调失败 |

## 2. 告警

- 关键任务积压；
- 大量运行停留 running；
- 关键检查覆盖不完整却尝试完成；
- 模型或解析错误率突增；
- 财务/合同映射版本漂移；
- 回调连续失败或版本冲突；
- 租户越权、防重放或异常导出；
- 单案成本超预算。

## 3. 日志

操作日志只记录经白名单校验的安全状态字段，不记录合同全文、查询参数、个人信息、密钥、异常正文或隐藏思维链。当前 HTTP 操作记录含 request/trace ID，workflow/outbox 记录可含 tenant/trace ID；不把这些字段作为指标维度。需要案件/主体定位的安全审计事件走独立审计表与授权查询，不复用高吞吐指标或一般操作日志；访问敏感证据单独记录审计日志。运行日志的访问控制和保留期仍待目标环境审批。

M0 已实现 API 请求、Worker 任务和 outbox 投递的 OpenTelemetry span；`traceparent` 随持久任务与事件跨进程传递。API 生成服务端 request ID，span 只记 HTTP 方法、静态路由模板、状态及稳定业务 ID；任务与事件 span 只记稳定 ID、类型、尝试次数及结果枚举。结构化操作日志记录状态与耗时并拒绝未知字段或格式不合规的值，不写请求参数、任务 payload、合同文本或异常正文。操作事件同步记录低基数计数器和耗时直方图：HTTP 维度仅使用方法、静态路由及状态类别；Worker/outbox 使用操作名与有限结果枚举；不附租户、案件、运行、任务、trace 或 request ID。workflow task、outbox、文档解析和 PageIndex 索引均记录实际领取等待时长直方图，等待时长不作为维度。默认不导出；`CONTRACT_OTEL_EXPORTER=console` 启用本地 span/周期指标控制台 exporter，旧 `CONTRACT_OTEL_CONSOLE=1` 仍兼容；`CONTRACT_OTEL_EXPORTER=otlp` 可选启用批量 traces 与周期 metrics 导出，默认 HTTP/protobuf，也支持 gRPC，并读取标准 `OTEL_EXPORTER_OTLP_*` endpoint/header/protocol 环境变量。OTLP 日志未启用。此实现不提供/配置 collector，也不等于生产观测验收：目标 collector 身份、网络/凭证访问控制、数据驻留与保留、采样、仪表盘、告警、模型/连接器专属指标仍待设计和批准；队列深度的跨租户安全聚合仍未解决。
