# 备份恢复方案

> 版本：v1.0｜状态：已批准（MVP 方案；演练待执行）  
> 负责人：内部技术负责人  
> 批准人：内部项目发起人  
> 适用阶段：M4  
> 上游依据：Phase 0 试点定义包、部署方案 v1.0  
> 目标：RTO 4 小时，RPO 1 小时

## 1. 对象

- PostgreSQL 全量与增量备份；
- 对象存储版本/复制；
- 规则包、Prompt、配置和基础设施代码；
- 密钥元数据与恢复程序；
- 检索索引可由真源重建，不作为唯一备份。

## 2. 恢复优先级

身份与权限 → 案件/任务/决定 → 原件与证据 → 规则知识 → 检索索引 → 报表缓存。

## 3. 演练

至少验证：数据库时间点恢复、对象缺失、Worker 全部重启、单区域不可用、checkpoint 丢失、回调 outbox 重放和已删除数据重新应用。

## 4. 一致性检查

恢复后核对快照哈希、任务租约、outbox、对象引用、规则版本和决定记录。无法确认一致性的案件进入人工冻结，不自动继续外部流程。

## 5. 验收记录

方案批准不代表恢复能力已通过。进入 mvp 环境前必须记录演练日期、备份点、恢复耗时、数据损失窗口、哈希核对、失败项、责任人和复测结果；超过 RTO/RPO 即 G7 不通过。
