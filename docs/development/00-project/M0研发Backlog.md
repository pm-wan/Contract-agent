## 3. 通用完成定义

- 代码、迁移、契约和测试同一提交可复现；
- 不提交密钥、真实合同、生产数据或模型隐藏推理；
- 新接口必须有成功、非法输入、无权限、冲突和服务失败测试；
- 新任务必须有重复执行、租约过期、取消和 superseded 测试；
- 新规则必须有正例、反例、缺材料和冲突样例；
- 变更同步更新受影响的 OpenAPI、Schema、迁移和文档。
