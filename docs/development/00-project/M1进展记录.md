> 产品决定补记：主体由审核人确认后锁定，普通审核人不能直接更改；错误只能由主体管理员走纠错流程并追加审计。管理员使用独立的租户级 `tenant_entity_administrators` 授权记录，由受信数据库运维流程预置/撤销；不读取 OIDC 角色声明，也不把 `operator` 运维身份等同于业务管理员。管理员可在材料选择、授权或输入冻结后纠错：撤销已有材料选择与授权、递增案件版本、将旧范围运行标记为 superseded，旧快照/运行记录保留为历史但不原地修改；新审查必须重新准备。旧结果仍按当前成员和材料授权重新鉴权。

> 金额授权覆盖已存结果（2026-09-26）：增强运行结果 API 的 PostgreSQL 纵向测试，在已授权时读取绑定证据的金额型付款候选成功；仅撤销该来源的 `allow_amount`、保留案件成员/材料选择/文本权限后，同一已存结果读取立即 403，恢复金额权限后读取恢复成功。该断言验证结果读取按当前金额权限复核整个派生结果，而不只复核候选引用来源；测试使用隔离 PostgreSQL 18 空库并应用迁移 001～030，定向用例 1 passed。没有改变生产权限或新增金额派生字段。
