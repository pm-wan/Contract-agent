# 责任矩阵

> 版本：v1.1 候选｜状态：按新 MVP 范围修订中

## RACI

| 事项 | 产品 | 法务 | 财务 | 技术 | 安全 | QA | 业务方 |
|---|---|---|---|---|---|---|---|
| 首期范围 | R | C | C | C | C | C | A |
| 法律规则及依据 | C | A/R | I | C | I | C | C |
| 企业审查立场 | C | R | C | I | I | C | A |
| 财务字段及口径 | C | C | A/R | C | I | C | C |
| 领域模型 | C | C | C | A/R | C | C | I |
| 模型与工具权限 | C | C | I | R | A | C | I |
| 金标与争议裁决 | C | A/R | R | C | I | R | C |
| 生产发布 | C | C | C | R | A | R | I |
| 最终案件决定 | I | C | C | I | I | I | A/R |

`R` 执行，`A` 最终负责，`C` 参与咨询，`I` 知会。

## 内部角色

| 角色 | MVP 责任主体 | 替补 | 备注 |
|---|---|---|---|
| 项目负责人 | 内部项目负责人 | 内部技术负责人 | 姓名可后补，不阻塞启动 |
| 产品负责人 | 内部产品负责人 | 内部项目负责人 | 兼任允许 |
| 规则 DRI | 内部规则负责人 | 内部项目负责人 | MVP 不设外部法务依赖 |
| 财务数据 DRI | 财务部门指定负责人（待落实） | 内部产品负责人 | M3 前确认真实 API、主体/往来与结清/逾期口径 |
| 合同系统 DRI | 合同系统指定负责人（待落实） | 内部产品负责人 | M3 前确认曾签状态、权限、版本与候选字段 |
| 企业知识发布 DRI | 企业指定知识负责人（待落实） | 内部规则负责人 | 确认内部知识的审核、发布与版本 |
| 技术负责人 | 内部技术负责人 | 内部后端负责人 | 负责架构和发布 |
| 安全负责人 | 内部技术负责人 | 内部项目负责人 | MVP 阶段可兼任 |
| QA 负责人 | 内部测试负责人 | 内部产品负责人 | 保持盲测集隔离 |

## 人工权限

- 主体映射确认：财务/主数据授权角色；
- 合同关系确认：合同管理员或业务负责人；
- 法律事实冲突：法务 DRI 或其授权人；
- 企业例外：审批矩阵指定角色；
- 规则发布：规则作者与批准人分离；
- 生产回写：应用权限与外部系统权限双重校验。
