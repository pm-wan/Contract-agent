## D. 样本与金标

- 开发样本数量：20 份；
- 独立验收样本数量：10 份；
- 分布：标准、风险、缺附件、冲突、扫描降级、角色异常和跨域反例；
- 标注人/复核人：内部规则负责人和产品负责人；分歧由内部项目负责人裁决；
- 数据使用合成或已脱敏授权材料，MVP 留存 180 天，到期复核删除。
