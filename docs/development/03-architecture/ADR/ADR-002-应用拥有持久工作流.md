# ADR-002：应用拥有持久工作流

> 状态：已接受｜日期：2026-09-17

## 背景

合同审计存在人工等待、外部数据、重复投递、取消、版本替换和长时间恢复需求。

## 决定

应用数据库保存任务和业务状态；AgentScope 只处理单任务内部受限模型/工具编排，PageIndex 只提供检索能力，均不作为案件业务真源。语言/框架决策由 ADR-004 管理。

## 后果

需要自行实现任务租约、幂等、outbox 和恢复测试，但可避免框架升级或 checkpoint 丢失破坏业务记录。

## 验证

执行 Worker kill、重复领取、过期提交、人工等待和 checkpoint 丢失演练。

## 回滚条件

若任务规模、跨服务编排或运维成本经量化超过 PostgreSQL 方案能力，再以新 ADR 评估独立工作流引擎；迁移前数据库业务状态仍是真源。
