# 合同审计 Skills

## 开发用 MD Skill

本目录七个 `SKILL.md` 是开发和评审过程中供模型使用的审查方法说明，可用于样例推演、规则提取和提示验证。它们尚未通过平台的规则发布、法律/企业知识核验和运行评测门禁，**不代表平台已上线或获批准的正式审核规则**。文档中的 `full_review` 等模式用于开发验证；正式运行仍由应用的审计计划决定覆盖范围。

- [中国采购合同审计](cn-procurement-contract-audit/SKILL.md)：我方为采购方、客户、服务接受方或被许可方。
- [中国销售合同审计](cn-sales-contract-audit/SKILL.md)：我方为销售方、供应商、服务提供方或许可方。
- [中国劳动人事合同审计](cn-employment-contract-audit/SKILL.md)：劳动关系、入职、履行、变更、限制性协议和解除终止。
- [中国知识产权与技术合同审计](cn-ip-technology-contract-audit/SKILL.md)：权利链、许可、技术开发、开源组件和 AI 交付物。
- [中国数据与隐私合同审计](cn-data-privacy-contract-audit/SKILL.md)：数据流、处理角色、DPA、共享、出境和安全附件。
- [中国投资股权与公司治理审计](cn-corporate-investment-audit/SKILL.md)：资本结构、投资条款、股权转让、治理、退出和交割。
- [中国融资担保合同审计](cn-financing-guarantee-audit/SKILL.md)：借款、授信、保证、抵押质押、顺位和执行。

每个开发用 Skill 独立维护适用范围、规则目录、证据约束和输出 Schema，便于模型使用和研发迭代。不得通过简单替换交易角色在不同合同领域之间复用结论。正式平台检查需另行发布规则、知识引用、评测与运行绑定；开发用 MD 不自动成为发布物。

未来平台运行用 Skill 仍以 MD 文本作为给模型的规范。其版本、审批状态、内容哈希、引用的规则和知识版本可以由数据库管理；数据库管理的是元数据与绑定关系，不要求把模型读取的规范改成数据库字段拼接文本。具体存储和发布方案在实施设计时确定。
