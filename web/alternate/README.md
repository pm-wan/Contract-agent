# 案牍备选工作台

这是与原前端并列的视觉方案，原入口 `/` 和旧页面都保留。独立入口为 `/alternate/`，复用 `web/src/api.ts`、当前 API 代理与相同后端权限，不另造演示数据。

该入口使用主工作台的本地账号登录会话；登录后显示当前成员，并可从顶部退出。首次登录需要先修改管理员设置的初始密码。新租户的首位管理员仍需按主 README 的步骤从 API 环境初始化。

本机开发时确保 API 和 Web 开发服务器已启动；从仓库根目录运行：

```bash
set -a; . ./.env; set +a
pnpm --dir web dev
```

打开 `http://127.0.0.1:5173/alternate/`。生产构建通过 `pnpm --dir web build` 同时生成原入口与本备选入口。

目前本方案覆盖案件台账、案件创建、案件详情、人工签约主体确认和 PDF/DOCX 上传；案件详情提供“继续审核此主合同”，直达主入口当前案件。主入口提供显式开启的开发审核及结果查看，人工任务继续由原入口提供。上传、解析、索引和模型读取授权按服务端状态分别显示。
